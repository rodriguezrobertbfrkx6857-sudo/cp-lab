# UI / UX Specification

## Desired feel

Keywords:

- Minimal
- Premium
- Soft
- Technical
- Editorial
- Dashboard
- Developer Tool

The design should feel closer to a refined modern SaaS/developer dashboard than to an online judge.

## Layout principles

- use generous whitespace,
- prioritize hierarchy,
- keep cards large and calm,
- avoid excessive decoration,
- use high information density only where it improves analysis,
- keep charts visually integrated with the UI.

## Interaction

Transitions:
- generally 180–240ms
- subtle easing
- no gratuitous parallax
- no attention-seeking animation loops

Hover:
- small elevation / border change
- never large scale jumps

Focus:
- visible and keyboard accessible

## Visual prohibitions

- no giant gradients,
- no excessive glow,
- no cyberpunk aesthetic,
- no "Bootstrap default" appearance,
- no random neon colors,
- no excessive glassmorphism,
- no huge marketing text occupying half the viewport,
- no inconsistent card radii,
- no emoji as primary UI icons,
- no random stock illustrations,
- no copied branding,
- no copied logos,
- no copied people or profile imagery from references,
- no copied watermark or textual content from references.

## Visual reference usage

The images in `visual_reference/` are mood references only.

Extract:
- spacing,
- rounded-card language,
- clean information hierarchy,
- restrained palette,
- soft elevation,
- dashboard composition,
- center-canvas workbench ideas.

Do not reproduce exact interfaces.
