# Responsive Rules

## Desktop 1440+
Full three-panel playground.

## Laptop 1024–1439
Keep three panels where possible; allow narrower controls.

## Tablet 768–1023
Reflow:
- visualization first
- controls second
- state third
- timeline/code below

## Mobile <768
Use stacked sections.
Keep navigation usable.
Do not attempt to squeeze desktop workbench columns into phone width.

Tables should become:
- horizontally scrollable only where necessary,
- or card-based summaries when that preserves readability.
