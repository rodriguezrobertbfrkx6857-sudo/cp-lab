# Promotion Specification

The repository should generate reusable promotional material.

## Required visual assets after implementation

- 16:9 Dashboard screenshot
- 16:9 Playground screenshot
- 16:9 Benchmark screenshot
- 9:16 vertical crop/layout for short-form content
- 5–12 second Dashboard GIF
- 5–12 second Dijkstra GIF
- 5–12 second Benchmark GIF

## Good content angles

- "I visualized Dijkstra step by step."
- "Why O(n) and O(log n) feel so different."
- "Euler sieve vs Eratosthenes in real benchmarks."
- "What path compression actually changes."
- "C++ vs Python on the same algorithm."
- "I built a competitive-programming algorithm laboratory."

## Promotional rule

Promotional visuals should come from the actual working product, not separate fake mockups that imply unavailable functionality.
