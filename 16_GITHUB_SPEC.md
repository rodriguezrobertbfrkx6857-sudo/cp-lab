# GitHub Specification

## Repository impression

The repository should feel like a maintained open-source project.

Required:
- README.md
- LICENSE
- CONTRIBUTING.md
- CODE_OF_CONDUCT.md
- CHANGELOG.md
- ROADMAP.md
- ARCHITECTURE.md
- SECURITY.md

## Topics

Suggested:
- competitive-programming
- algorithms
- algorithm-visualization
- data-structures
- benchmark
- cpp
- python
- nextjs
- fastapi
- computer-science

## CI

GitHub Actions should run:
- frontend install
- lint
- type check
- frontend tests
- backend tests
- algorithm tests
- production build
- Playwright smoke tests where practical

## README first screen

Should contain:
- project name
- one-line description
- Visualize · Experiment · Benchmark · Compare
- Live Demo button placeholder/configurable
- Documentation
- Getting Started
- badges
- hero screenshot or short demo GIF

Do not begin with a wall of installation text.

## Screenshot set

Prepare:
- Dashboard
- Algorithm Explorer
- Algorithm Detail
- Dijkstra Playground
- Euler Sieve Visualization
- Benchmark Compare

## Demo GIFs

Target:
- 5–12 seconds
- compact
- smooth
- no irrelevant cursor movement
