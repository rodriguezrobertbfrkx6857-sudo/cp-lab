# V1 Scope

## Included

- Dashboard
- Algorithm Explorer
- Algorithm Detail
- Playground
- Benchmark Lab
- Compare
- Documentation page
- About page
- 20 curated algorithms
- C++20 implementations
- Python implementations
- step-based visualization system
- deterministic dataset generation
- reproducible benchmark metadata
- responsive UI
- accessibility basics
- unit tests
- API tests
- end-to-end smoke tests
- Docker development setup
- GitHub Actions CI
- README and project documentation

## Explicitly excluded from V1

- account registration
- authentication
- cloud sync
- community features
- online judge
- arbitrary user code execution
- Codeforces API integration
- leaderboards
- social feeds
- AI explainer
- AI bug diagnosis
- AI test-case generation
- dark mode
- paid features

## V1 principle

Prefer 20 complete algorithms over 150 shallow entries.

No feature should exist only as an empty card, dummy button, or hard-coded demonstration if the specification expects real behavior.
