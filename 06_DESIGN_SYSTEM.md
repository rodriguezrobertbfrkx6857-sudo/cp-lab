# Design System

## Core colors

Suggested base tokens:

```css
--bg: #F5F7FA;
--surface: #FFFFFF;
--text-primary: #111318;
--text-secondary: #69717D;
--border: rgba(17, 24, 39, 0.08);
```

Accent families:
- indigo
- violet
- cyan
- emerald
- rose
- amber

Use accents sparingly and at restrained saturation.

## Typography

Preferred:
- Geist
- Inter
- equivalent modern sans-serif fallback

Principles:
- strong numerical hierarchy
- compact headings
- readable code
- avoid oversized hero type

## Radius

- card: 20px
- button: 12px
- input: 10–12px
- badge: pill or 8–10px depending context

## Sizing

- sidebar collapsed: 72px
- button height: 40–44px
- input height: ~40px
- main max width: ~1600px

## Elevation

Use:
- subtle border
- very light shadow

Avoid dramatic floating cards.

## Charts

- light axes
- very subtle grid
- ~2px lines
- white/soft tooltip cards
- restrained series palette
- no default rainbow chart palette

## Motion

- 180–240ms
- support `prefers-reduced-motion`
