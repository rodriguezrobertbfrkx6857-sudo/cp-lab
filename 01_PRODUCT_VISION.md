# Product Vision

## Positioning

CP-Lab is a modern interactive laboratory for competitive-programming algorithms.

Tagline:

> Visualize · Experiment · Benchmark · Compare

The product is built around six ideas:

1. Understand an algorithm.
2. Run it on concrete input.
3. Inspect execution state step by step.
4. Modify inputs and experiment.
5. Compare alternative approaches.
6. Measure real performance reproducibly.

## What makes CP-Lab distinct

Many algorithm visualizers stop at animation. CP-Lab should emphasize experimentation and engineering:

- strong number-theory coverage,
- competitive-programming orientation,
- C++20 and Python implementations,
- a unified visualization-step model,
- reproducible benchmark methodology,
- explicit runtime/environment metadata,
- polished dashboard-style UX,
- GitHub-ready documentation and CI.

## Audience

Primary:
- competitive programming learners,
- CS students,
- algorithm interview learners,
- developers who want to inspect algorithm behavior.

Secondary:
- educators,
- open-source contributors,
- technical portfolio reviewers.

## Product promise

Every featured algorithm should be more than a code snippet. It should have:

- concise explanation,
- complexity,
- C++ implementation,
- Python implementation,
- examples,
- tests,
- visualization where specified,
- benchmark support where specified,
- related algorithms.

## V1 success condition

A reviewer should be able to open the repository or live demo and quickly conclude:

- the author understands algorithms,
- the project has real full-stack engineering,
- the UI is deliberate and cohesive,
- the benchmark methodology is not fake,
- the repository is maintained like an open-source project.
